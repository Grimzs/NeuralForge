📋 Таблицы (xlsx)

Общая структура: колонки x… — входы, y… — выходы, pX…/pY… — пояснения к соответствующим колонкам, колонка p (или «описание») — пояснение самой таблицы.

Файлы

Загружайте сразу несколько файлов — «Открыть все» добавит каждый в обработку. Клик по файлу — открыть в редакторе справа.

Открытая таблица — не открыта
пояснение таблицы (колонка p)

Клик по бейджу роли (x / y / pX / pY / —) меняет роль колонки. Заголовок колонки можно переименовать — роль пересчитается (например «temp» → «x3»).

Обработка нескольких файлов

Открытые таблицы обрабатываются вместе: строки склеиваются в общий датасет, либо колонки X разных файлов соединяются по строкам («для отдельных входных данных»).
